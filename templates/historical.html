📥 Import Historical Data from JSON Files

Import historical packet data from JSON file exports (TTN Storage API exports, custom datasets)

One file path per line. Supports JSON arrays, single objects, and JSONL format.
Comma-separated device IDs to import, or leave empty for all
Number of messages to process in each batch

Supported JSON Formats:

1. JSON Array Format:
[
  {
    "end_device_ids": { "device_id": "my-device" },
    "uplink_message": { "f_cnt": 123, "rssi": -85 },
    "received_at": "2025-07-24T10:00:00Z"
  },
  { ... more messages ... }
]
2. JSONL Format (one JSON object per line):
{"end_device_ids": {"device_id": "device-1"}, "uplink_message": {...}}
{"end_device_ids": {"device_id": "device-2"}, "uplink_message": {...}}
3. Single JSON Object:
{
  "end_device_ids": { "device_id": "my-device" },
  "uplink_message": { "f_cnt": 123, "rssi": -85 },
  "received_at": "2025-07-24T10:00:00Z"
}
📝 Note: JSON files should contain TTN message objects with standard TTN v3 format. The system will auto-detect the format and parse accordingly.
